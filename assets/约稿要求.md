# better-lessons 立绘约稿要求

## 0. 概览

给一个昔涟AI agent 交互式课堂插件画**四张**立绘。插件运行时会开一个**半屏窗口**，摆出文字游戏式的画面：左边是黑板，右下角是对话框，她在两个位置上出现——

- **右下角（近景）**：只出现**上半身**，抱着书，面向观众说话；
- **黑板前（中景）**：**全身、完全背身**，踮着脚在黑板上写字或擦板。

两者是**两个不同位置的独立素材**，切换时是交叉淡入淡出（她淡出的同时另一张淡入）。所以四张图要**成组**看：站位、尺度、光照必须对得上。

角色形态：**哀丽秘榭的小昔涟（粉色短发）**。

## 1. 交付物

| 文件 | 内容 | 画布 | 体积 |
|---|---|---|---|
| `cyrene-talk.png` | 讲述：**半身**，右下近景，双手抱书讲解姿态 | 900 × 1100 | ≤ 1.5 MiB |
| `cyrene-write.png` | 板书：**全身背身**，踮脚板书，手握粉笔看向笔尖 | 900 × 1400 | ≤ 1.5 MiB |
| `cyrene-erase.png` | 擦板：**全身背身**，踮脚擦板，手持黑板擦（主帧） | 900 × 1400 | ≤ 1.5 MiB |
| `cyrene-erase-swing.png` | 擦板**挥舞差分**：只改手臂 / 黑板擦 / 发梢等被带动的位置 | 900 × 1400 | ≤ 1.5 MiB |

统一要求：

- PNG-24 + 透明通道，sRGB；**背景全透明**。
- 若能同时给分层源文件（PSD / CLIP 皆可）更好

**三张全身图（write / erase / erase-swing）必须严格同尺寸、同锚点**：脚底（踮起的脚尖）距画布下边距离一致、身体中轴对齐同一竖线。因为擦板时这两帧每 **380ms 交替一次**，锚点差一点就会看见人物在抖。

**讲述那张与它们不要求同锚点**（它单独占一个槽位、位置也不同），但画布内请把**头顶距上边留约 50px**，让它的显示高度可控。

## 2. 显示环境（决定构图，请先看这段）

窗口是半屏的，约 960 × 1040 可用像素。

### 讲述槽（右下，半身）

- 显示高度 = 窗口高的 46% ≈ **478 px**；按 900×1100 的比例，显示宽度 ≈ **391 px**
- 锚点：**右下角**（右边距 1%、底边距 25%），底边正好坐在对话框上沿——所以**画布下缘就是"被对话框切掉"的位置**，请把下缘切在**胯部（大腿上部）**，不要切得太高（会像半截人）
- **她是近景，视觉上比板书那张更大**：同一屏幕下，这张的头部尺寸约是板书那张的 **1.5 倍**。这是刻意的"半身放大"效果，请照近景的完成度画（脸和手是重点）
- **每点一次鼠标，这张会向上轻跳一下**（`translateY 0 → -12px → 0`，约 260ms）。所以头顶上方要留出约 20px 余量，别贴住画布上边

### 板书 / 擦板槽（黑板前，全身背身）

- 显示高度 = 窗口高的 58% ≈ **603 px**；按 900×1400 的比例，显示宽度 ≈ **388 px**
- 位置：**黑板前偏右**，脚底距窗口底边约 30%（略低于黑板下沿，像站在讲台前）
- 这块区域**会被黑板压住一部分**：黑板占窗口左侧 78%，她站在偏右的位置，**她的身体左侧约三分之一会叠在黑板上**。这不影响观看（她画在黑板之上），但请保证**人物轮廓完整**
- 她**完全背身**：观众看到的是背影与侧后方，看不到脸。所以这张不承担表情表演，重点在**体态与动作的可读性**——踮脚的发力、抬臂的高度、粉笔与黑板擦的位置

**偏右是有意的**：板书内容左对齐，站在偏右压住的是最右侧，损失最小。

## 3. 四张图的表演要求

### a) `cyrene-talk.png` 讲述（半身，面向观众）

- 双手在胸前**抱住一本书**（书本设定参考：如我所书。抱得自然，别举得太高挡住脸）
- 视线：朝观众
- 表情：温柔含笑，眼睛睁开有神，嘴部微张（"讲到一半"的嘴型）
- 感觉：**"来，我们一起看看这个。"**
- 注意：要留出**跳动的余量**（头顶上方约 20px 空）；手与书不要伸出画布左右边缘

### b) `cyrene-write.png` 板书（全身背身）

- **完全背身**朝黑板，身体朝黑板略微侧转一点点（约 10°–15° 即可，**不要转成侧脸**）
- **踮脚**：双脚并起、脚跟离地，身体重心略前倾，肩膀一高一低（抬起的那侧更高）
- 抬起的手臂在黑板上书写，**手握粉笔**，**视线落在笔尖上**（背身状态下表现为后脑与肩线朝向抬起的手臂）
- 另一只手可自然垂放或轻扶衣摆 / 抱在身侧
- 穿着上请**让裙摆与袖口有一点被动作带起的感觉**，避免完全静止的立正姿势

### c) `cyrene-erase.png` 擦板主帧（全身背身）

- 同样是**背身 + 踮脚**，但手臂抬得比板书**更高一点**
- 手持**黑板擦**，手掌压实擦板面
- 身体可以有一点被抬手带起来的**侧倾**，肩线明显倾斜
- 与板书那张的关系：**站位、脚位、朝向完全一致**，只有手臂与身体倾角变化

### d) `cyrene-erase-swing.png` 擦板挥舞差分（全身背身）

- **只改会被挥舞带动的部分**：手臂的角度（比主帧再抬高或向外挥出）、黑板擦的位置、发梢/衣摆/丝带的飘动方向
- **不要动**：脚位、腿部、身体中轴、头部位置、另一半身体——一切都与主帧严格对齐
- 目标效果：两张交替播放时，看起来像来回挥动黑板擦。但动作幅度不宜过大，否则看起来会抽搐。

## 4. 四张图之间的一致要求

1. **同一光照**：四张是同一时刻同一光照，不能出现"手臂粗细变了""布料颜色深浅变了""光源换边了"
2. **尺度一致**：全身三张里人物身高完全一样；讲述那张是近景放大（约 1.5 倍），但**头身比例必须一致**
3. **发色 / 服装配色在四张间完全一致**——建议先定一张色卡再画其余三张

## 5. 角色设定

昔涟（Cyrene），《崩坏：星穹铁道》翁法罗斯篇章角色，来自城邦「哀丽秘榭」，被称为「记忆」的孩子、祭司；俏皮、温柔、外冷内热、爱写诗、爱开玩笑，喜欢自称"人家"，被盯着看久了会害羞。

**这一组是「小昔涟」形态（粉色短发）**，请以官方该形态的立绘 / 建模为唯一参考（恕不提供非官方同人图）。特征：

- **粉色短发**（发梢有渐变），**蓝色眼睛**，**尖耳朵**
- 黄金裔的装饰元素：**双生花、宝石、丝带**
- 哀丽秘榭 / 祭司身份的服饰基调
- 「记忆」与冰的主题：**水晶花、冰晶、流光**这类点缀都合适
- 气质基调：干净、温柔、可信。**不做性感化处理**——这是教学场景

**若我写的细节与官方设定有出入，一律以官方为准。**

## 6. 验收

### 6.1 精细度

"高精度""精致"这类词无法验收，所以按下面四条对齐：

| 项 | 要求 |
|---|---|
| **级别** | **伪厚涂游戏立绘**。有明确的光影分层、材质区分（布料 / 金属 / 皮肤 / 头发）、服饰褶皱有结构 |
| **明暗** | 至少 **2–3 层**（基调 / 主阴影 / 局部最深），**受光方向唯一且明确**，四张必须一致。允许厚涂笔触，但不接受"糊成一团"的过渡 |
| **线稿** | 干净、闭合。**放大 200% 看不能有断线、粗细突变、抖动** |
| **头发** | 分组清晰（大块 + 发梢细分），不糊成一片色块 |

### 6.2 其余要点

1. **显示尺寸很小**：屏幕上只有约 440×690，还是半屏窗口的一角。细节会被缩小吃掉，所以真正决定观感的是**大关系**——剪影一眼认得出是谁、明暗在小尺寸下仍分得开。
2. **背景是深墨绿黑板**：她的边缘如果是深色，会和背景糊在一起。请在轮廓上留一点受光或亮色分离（发丝边缘、肩线、衣摆），让人物整体**比黑板亮**。
3. **近景那张要经得起看**：`cyrene-talk.png` 的头部显示约为板书那张的 **1.5 倍**，脸和手是这四张里唯一会被放大细看的地方，完成度请优先堆在这里（抱书的手，结构要成立）。

### 6.3 验收清单

- [ ] 线稿放大 200% 无断线、无锯齿
- [ ] 明暗至少 2 层，四张受光方向一致
- [ ] 发丝分组清晰，未糊成色块
- [ ] 透明边缘无白边、无半透明脏边
- [ ] 人体结构正确，面部、抱书的手、握粉笔的手，结构成立
- [ ] 四张的发色、服饰配色、光照方向一致
- [ ] 三张全身图的脚底与中轴对齐，擦板差分与主帧严丝合缝

## 7. 明确不要做的事

1. 不要画背景、地面、投影、外发光、边框、文字、水印、签名
2. 不要四张各画各的——必须共用同一套尺度、光照与配色
3. 不要改变画布尺寸、不要裁切、画布上不要有非人物的像素
4. 不要把人物画满整幅宽度——`talk` 的左右、`write`/`erase` 的左侧都请留余量
5. 不要把背身画成侧脸（要的"完全背身"，是看不到五官的）

## 8. 建议流程

**流程**：四张并排的姿势草图 → 确认站位、动作与尺度 → 线稿（先出 `write` 一张定稿） → 其余三张按它对齐 → 上色 → 交付。

**先出 `cyrene-write.png` 的线稿 + 上色**，确认画风与精细度之后再画其余三张，减少返工。**建议按"草图 → 线稿 → 上色"分三次交付确认**。
